# Quiz Application with Timer 🧠

## CODSOFT Java Development Internship - Task 4

### Project Description

The Quiz Application is a web-based quiz project developed using HTML, CSS, and JavaScript.

The application displays multiple-choice questions one at a time and provides a 10-second timer for each question. Users can select an answer, move to the next question, and view their final score after completing the quiz.

### Features

- Multiple-choice quiz questions
- One question displayed at a time
- 10-second timer for each question
- Automatic movement to the next question when time expires
- Answer selection
- Score calculation
- Final result screen
- Restart Quiz option
- Responsive and user-friendly interface

### Technologies Used

- HTML5
- CSS3
- JavaScript

### Concepts Practiced

- HTML structure
- CSS styling
- JavaScript variables and functions
- Arrays and objects
- DOM manipulation
- Event listeners
- Conditional statements
- Timers using setInterval()
- Dynamic question rendering
- Score calculation

### How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html.
4. Run it using Live Server.
5. The Quiz Application will open in your browser.
